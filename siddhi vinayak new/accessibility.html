Accessibility statement

This site is built to be usable by everyone, including buyers using keyboards, screen readers, zoom or reduced motion. Here is what we target, what we test, and the gaps we know about.

Last reviewed: 26 September 2026

Our commitment

We target WCAG 2.2 level AA across all pages of this site. The site is a plain HTML, CSS and JavaScript build with no framework layer, which keeps the markup close to the standard structure assistive technology expects.

What that means in practice

  • A skip link, one h1 per page, and headings that descend in order without skipping levels.
  • Every control works from the keyboard with a visible focus indicator; no keyboard traps.
  • Text meets AA contrast against its background, and reflows to 320 CSS pixels without horizontal scrolling.
  • All informative illustrations carry alternative text; decorative marks are hidden from assistive technology.
  • Forms use persistent labels, plain-language errors, and status messages announced to screen readers.
  • Respect for prefers-reduced-motion: reveal animations and smooth scrolling switch off when you ask.
  • Zoom to 200% and text resize remain supported; tap targets on small screens are sized for touch.

Known gaps

The product filter on the products page updates results live; result counts are announced, but the chip group could expose a richer radio-group pattern in a future revision. Some older export documents we may send as PDFs are not yet tagged for screen readers; on request we supply the same content in accessible HTML or plain text.

How we test

Pages are checked with keyboard-only navigation, browser zoom at 200%, Windows High Contrast where applicable, and automated checks as part of npm run check. Content is reviewed against the criteria each time pages change.

Tell us if something does not work

If any part of this site creates a barrier for you, write through the contact page describing the page, what you were trying to do and the assistive technology you use. We aim to acknowledge within seven days and provide the information in an alternative format promptly.

Need information in another format?

Specifications, quotations and policy pages can be supplied as plain text or accessible HTML on request.
